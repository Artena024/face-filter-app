# AR Face Filter App

Real-time face detection with beautiful AR filters.

## Features
- 📷 Real-time face detection (MediaPipe)
- 😊 6 Different filters
- 📸 Capture images
- 🎥 Record videos
- 📱 Mobile responsive

## Filters
- None
- Emoji Face
- Hearts
- Stars
- Blur Effect
- Beauty Filter

## How to Use
1. Open the app
2. Click "Start Camera"
3. Select a filter
4. Capture or record
